# Food Data

The bundled catalogue is synthetic/curated development data with serving context and an `athleteos_curated_v1` source label. It covers the required Indian golden queries and a compact global set; it is not a substitute for a licensed production dataset.

Production ingestion follows immutable snapshot → licence review → staging → unit normalization → aliases → anomaly checks → reviewed publish. IFCT or packaged-food records must not be imported until their usage/redistribution terms are recorded.
